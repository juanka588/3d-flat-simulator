# M5 — Assets & furniture (strategy, 2026-10-27)

**Status:** all stories M5.0–M5.18 are implemented (phase 3: e2e, furnish demo, docs). Pending: QA fixes and the user check-in. Demo results: see "Demo results" at the end.

Goal: the automatic designer only places **real, purchasable products** — never invented furniture.

## Product-grounded design
- Every placed item references a **product record**: provider, SKU, name, price, currency, URL, exact dims (w/d/h), category, style tags, photo URL.
- Its 3D shape is resolved in order: (1) the provider's real model **streamed through the user's local scene server** for personal viewing (memory-cached, never committed or served from Pages); (2) a CC0 lookalike from our library scaled to the exact dims; (3) a parametric shape at exact dims.
- The LLM can only place items returned by `search_products` / `search_assets` (no free-form furniture).

## Spike results & user decisions (2026-10-27) — see docs/research/m5-retailer-spike.md
- **IKEA FR connector: yes, personal use.** Search + product details + real GLB streamed via the local server only; memory cache with TTL; never committed, never served from Pages; may break without notice.
- **"Paste a product URL" provider: yes.** Single page fetched on user request via the local server; reads schema.org Product/3DModel JSON-LD; lookalike/parametric mesh at exact dims when no 3D; fails clearly on protected sites (Leroy Merlin, Maisons du Monde, La Redoute, Darty block scripts).
- **Saved flats keep reference + snapshot:** provider, SKU, URL, price/dims snapshot + date; no photos or 3D in the file (re-streamed on open).
- **Awin affiliate feeds: planned** (user signs up; official prices for M9 budget; no 3D, free-text dims).

# Refinement (2026-10-27)

## Decisions
- **D1 Item schema (additive, v1):** `productRef {provider, sku}`, `product` snapshot (name, url, price TTC, currency, dims, category, snapshotAt; no photos/3D), `mount floor|wall|ceiling`, `dims`, `variant`, `mesh: provider | lookalike{assetId} | parametric{generator, params}`, `clearance`, `locked`, `relation`. Legacy `builtin:*` items still load.
- **D2 Catalog:** `ProductRecord` (buyable, provider-sourced, server memory only) vs `MeshAsset` (geometry: parametric / cc0 / local:3dfuture). Resolution chain: real provider GLB (local server) → CC0 lookalike scaled to exact dims (≤ 25 % aspect distortion) → parametric at exact dims.
- **D3 Providers** (`apps/server/src/providers/`): plugin interface (search, get, fetchModel), enabled via `FLAT_PROVIDERS`, memory LRU+TTL (search 10 min, product 1 h, GLB 1 h, 200 MB/20 MB caps), politeness (UA, 1 req/host, 1.5 s gap, robots.txt, circuit breaker on 403/429, GET only), credentials only from env, redacted.
- **D4 Local-only guards:** import boundary (ESLint + graph test), `check-no-retailer.mjs` on the Pages dist and `git ls-files` (retailer hosts, stray GLBs, `.env*`, 3D-FUTURE), scene-serialisation key allow-list, loopback/Origin on routes, Pages zero-retailer-request e2e.
- **D5 Model pipeline** (`scripts/models/`, mirrors materials): Poly Haven / Kenney / Quaternius / Objaverse (per-object cc0|by only), gltf-transform normalise (pivot = item frame, Meshopt, WebP ≤ 1024), ≤ 300 KB/model, ≤ 6 MB total, ≤ 20k tris; provider GLBs streamed un-normalised, auto-pivot + scale to dims.
- **D6 Parametric generators** (pure `MeshData`): wardrobe, kitchen base/wall, bookshelf, bed, table, chair, sofa, desk, nightstand, sideboard, TV unit, mirror, rug — exact dims (±1 mm), deterministic, ≤ 3k tris.
- **D7 Placement:** relations (`against_wall`, `in_corner`, `centered_in`, `facing`, `next_to`, `under_window`, `at`) + deterministic bounded solver; hard constraints: inside room, no overlap (walls + items, height-aware), **door swing quarter-discs**, window clearance (only items under the sill), wall mounts not on glazing, **heavy mounts only on structural walls** (partition needs acknowledgement → warning), walkways ≥ 0.8 m (0.9 m at the entry), locked items untouchable; rationale + violations with alternatives.
- **D8 Commands:** `item.place / move / rotate / setVariant / remove` with exact inverses; LLM placements require a seen product; locked items protected from non-user authors; drag coalescing.
- **D9 MCP:** `list_providers`, `search_products`, `get_product`, `search_assets`, `get_placement_options`, `validate_layout`, `place_item`, `get_bill_of_materials`, `item_*`; **only real products**: opaque `productId` must have been returned by search in this session; price/dims always taken from the server's record, never from LLM args; `furnish_room {roomId, brief, budgetEur}` prompt.
- **D10 UI:** catalog panel (Products | Library, paste URL), personal-use banner, drag-to-place ghost (green/red with violation), snapping (grid, wall, 15°, corner), gizmo, item properties (price, date, link, mesh-source badge, lock), room item list with total.
- **D11 Budget hooks:** pure bill of materials (per room, totals, stale > 7 d, mixed currency) for M9.
- **D12 Tests/CI:** fast tier with recorded fixtures (no live network); live IKEA probe nightly; catalog e2e in async shards; bundle +40 kB budget.
