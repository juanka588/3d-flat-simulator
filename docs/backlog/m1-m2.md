# M1 + M2 refined backlog

Refined by the user-story agent and reviewed at the M0 check-in (2026-10-26).
Size: S ≤ ½ day, M 1–2 days, L 3–5 days. Test layers: **Vitest** (pure functions in `packages/scene`), **PW** (Playwright on `apps/web`), **Manual** (demo check).

Reference flat: `packages/scene/fixtures/charme-3205.flat.json` (the user's apartment, Blanc Nature – Charme n°3205, Bagneux, 2nd floor). The synthetic `sample.flat.json` stays as an edge-case fixture.

## Architecture rules
- `packages/scene` never imports `three`/`react` (ESLint `no-restricted-imports`). Geometry builders output plain typed arrays (`MeshData`); `apps/web` converts them to `BufferGeometry`.
- The viewer `<FlatCanvas scene view />` is a pure function of `Scene` + `ViewState`; all UI chrome lives outside it. The same component will back the MCP `render_view` tool (headless Playwright).
- `ViewState` (camera mode, sun date/time, lamp overrides) is separate from `Scene` — not part of undo/redo or autosave.
- Walls are built as boxes around openings directly (no CSG): exact to the mm, keeps per-face ownership (wall id + side) for picking and per-side finishes, cheap to rebuild.

**Key ACs**
- Wall lengths/heights match JSON within 1 mm; opening holes at `offset ± width/2`, `sill..sill+height`.
- Charme 3205 room areas within 15 % of the plan's listed areas each, total within 5 % of 72.14 m².
- Ceilings hidden in orbit/top; walk mode collides with walls and passes through doors.
- Clicking a wall shows id, side, dimensions, material; clicking a floor shows room name + area.

**Demo:** load Charme 3205 → orbit → top view (check compass) → click a wall and a room → walk from the entrance to Chambre 1 → drop a broken file and see the error list.

## Edge cases to cover (tests or warnings)
Wall junctions L/T/X/acute/mixed thickness/collinear; openings near corners or spanning T-junctions, sill+height = wall height; concave/CW/CCW rooms, overlapping rooms, unwalled edges (no holes supported); invalid JSON, wrong version, empty scene; spawn inside a wall; sun below horizon, polar day/night, DST gap/overlap, `northAngle` outside 0–360; z-fighting on wall tops, shadow acne, glass sorting, WebGL context loss.
